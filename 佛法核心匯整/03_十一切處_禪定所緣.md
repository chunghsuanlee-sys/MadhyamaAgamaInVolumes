# 十一切處：禪定的遍滿所緣

## 一、名目

**十一切處**（十遍處，巴利 kasiṇa）：地、水、火、風、青、黃、赤、白、空、識。修行者取一種所緣，觀想它「上下四方，無二無量」地遍滿一切處，使心專一不散。

| 類別 | 所緣 | 與中阿含其他教法的關聯 |
| :--- | :--- | :--- |
| 四大 | 地、水、火、風 | 六界觀（分別六界經）、象跡喻經之四大非我、想經之「不著地想」 |
| 四色 | 青、黃、赤、白 | 長壽王本起經中阿那律修「光明與見色」之定 |
| 無色 | 空、識 | 六界之空界、識界；四無色定之空無邊處、識無邊處 |

## 二、中阿含中的位置

1. **222 例經（例品・卷60）**——與三十七道品、十無學法並列為斷老死的三大法門。
2. **86 說處經（長壽王品・卷21）**——阿難為新出家比丘所說的種種「說處」中，列有十遍處。
3. **相關教法（非直接言「一切處」，但為其義理基礎）**——
   - 162 分別六界經（根本分別品・卷42）：六界（地、水、火、風、空、識）觀，「彼一切非我有，我非彼有」。
   - 106 想經（因品・卷26）：不於地、水、火、風等生起「是我」之想。
   - 72 長壽王本起經（長壽王品・卷17）：修定時光明與見色消失之障礙及對治。
   - 168 意行經（根本分別品・卷43）：禪定與無色定的次第。
   - 217 八城經（例品・卷60）：入四禪、四無量、無色定後再觀其無常，成為十二甘露門。

## 三、理論與思想

- **止的所緣**——十一切處屬於「止」（奢摩他）的修法，目的在令心統一、得禪定。它本身是世間定，須與「觀」配合才能導向解脫（八城經）。
- **四大與空識的雙重意義**——在「觀」的一面，地水火風空識是分析身心、證知非我的「六界」；在「止」的一面，則是讓心遍滿的禪相。同一對象，止觀兩用。
- **不執著所緣**——想經說聖者於地乃至一切「不想是我、不想屬我」——即使修成一切處定，也不把定境當作自我。

## 四、實踐方法（整理）

> 中阿含本身未詳述一切處的操作細節；以下依經中禪定次第（算數目揵連經、念處經之光明想）與早期佛教一般修法整理，供實修參考。

1. **前行**——持戒清淨、斷五蓋（貪欲、瞋恚、睡眠、掉悔、疑）。
2. **取相**——選一所緣（如一片土色圓盤、一缽清水、一處光明或一種顏色），專注凝視並記住其相。
3. **遍滿**——閉目時仍能清楚憶起其相後，將它向上下四方擴展，直至遍滿一切處、無邊無量。
4. **入禪**——心安住於遍滿之相，次第證得初禪至四禪；空、識二處則對應空無邊處、識無邊處定。
5. **轉觀**——出定後觀此定境「是有為、是思所作，無常、滅法」（八城經），不著於定樂。
